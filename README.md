# devenv [![Build](https://github.com/1mpu1se/devenv/actions/workflows/build.yml/badge.svg)](https://github.com/1mpu1se/devenv/actions/workflows/build.yml)
Окружение для разработки.


## #1 Запуск
1. Установить [Docker](https://docs.docker.com/get-started/) с [Docker Compose](https://docs.docker.com/compose/).
2. Скачать последний zip-релиз со [страницы релизов](https://github.com/1mpu1se/devenv/releases) и распаковать содержимое в отдельную папку.
3. Для запуска сервисов необходимо через терминал перейти в папку с файлом `docker-compose.yaml` и выполнить команду:
   
   ```sh
   docker compose up -d
   ```
   
   После загрузки изображений, сервисы станут доступны по данным, указанным ниже.


## #2 Остановка
Для остановки всех сервисов в той же папке необходимо выполнить команду:
   
```sh
docker compose down
```


## #3 Очистка окружения
Окружение запоминает данные, которые находились в нем во время работы.

Для того, чтобы **полностью очистить** окружение необходимо:
1. Остановить и дождаться остановки всех сервисов.
2. Удалить папку `data`.

Для иого, чтобы удалить данные **отдельного сервиса** необходимо:
1. Остановить и дождаться остановки всех сервисов.
2. Перейти в папку `data` и удалить папку с названием нужного сервиса.
